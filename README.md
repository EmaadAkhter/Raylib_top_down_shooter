
# Raylib Top Down Shooter

This is a 2D top-down shooting game made with Raylib where the player (Archer) navigates a maze-like arena, avoiding walls and shooting at incoming enemies (Orcs)


## Demo

![Image](https://github.com/user-attachments/assets/67c77e0f-3f9f-42f5-8843-0a8fcff44270)
## Features

- Wall collision for both the player and enemies.

- Bullet shooting towards the mouse cursor.

- Enemies spawn periodically and chase the    player,   navigating around walls.

- Score system based on survival time and enemies killed.

- Lives system: player dies after 3 hits.

- Game over screen with a restart option.
